# Birthweight and Maternal Smoking: An Econometric Analysis

## Overview
This project investigates whether maternal smoking during pregnancy 
has a statistically significant effect on infant birthweight using 
OLS regression analysis in Python.

## Research Question
Does smoking during pregnancy affect the birthweight of newborns?

## Data
Dataset provided by Professor Douglas Almond, Kenneth Chay, and 
David Lee containing variables related to infant birthweight and 
maternal characteristics.

## Hypothesis
- H0: Smoking has no effect on infant birthweight
- H1: Smoking has a significant effect on infant birthweight
- Significance level: α = 0.05

## Methods
- Exploratory data analysis in Python
- OLS regression controlling for multiple variables affecting birthweight
- Hypothesis testing using p-values and coefficient significance

## Key Findings
- Smoking was found to be a probable cause of reduced birthweight
- Low p-values across key variable coefficients supported statistical 
  significance
- Results are consistent with public health literature on maternal 
  smoking and infant health outcomes
- Other unobserved variables may also contribute to birthweight changes

## Tools
Python, pandas, statsmodels

## Data Source
Almond, D., Chay, K., and Lee, D. — birthweight and maternal 
characteristics dataset
